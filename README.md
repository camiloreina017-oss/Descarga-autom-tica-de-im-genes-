# Bot de Automatización para Descarga de Imágenes (Selenium)

![Demostración](./AUTOMATIZACION%20IMAGEN.png)

###  ¿Qué problema resuelve?
Automatiza la búsqueda y descarga masiva de imágenes en alta resolución desde la web, eliminando el proceso manual de extracción y organizando los archivos descargados directamente en carpetas locales según el término buscado.

###  Tecnologías utilizadas
- **Python 3**
- **Selenium WebDriver & WebDriver Manager:** Automatización de la navegación web interactiva.
- **Requests:** Descarga de archivos de imágenes mediante peticiones HTTP[cite: 7].
